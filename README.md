# בודק ארבעת המינים

סימולטור אינטראקטיבי בעברית לבדיקת **כשרות** ואחריה **הידור** של אתרוג, לולב, הדס וערבה. מיועד לשימוש בטלפון, בזמן בחירת המינים.

- ארבעה מסלולים ובדיקת סט מלא (כולל האגד)
- תוצאת כשרות: 🟢 כשר / 🟠 ספק — שאלת רב / 🔴 פסול, עם הכלל שהכריע והמקור המדויק
- רמת הידור: ✓ / ○ / ? ודירוג ★★★–★★★★★. חוסר הידור לעולם אינו מוצג כפסול
- "למה בודקים את זה?" לכל שאלה, "למד אותי לבדוק", "בחן אותי"
- עובד בלי קליטה אחרי הביקור הראשון (PWA), מצב כהה ובהיר

## מקורות ההלכה — הכלל החשוב

האפליקציה **אינה יודעת הלכות מעצמה**. כל כלל נגזר אך ורק מהטקסטים הבאים, שנשמרו מילה במילה:

| קובץ | תפקיד |
|---|---|
| `src/sources/source-b.md` | **ילקוט יוסף, הלכות ארבעת המינים — העיקר** (מקור ב') |
| `src/sources/source-a.md` | **אתר כושרות — משלים** (מקור א'; הלכות לולב, סימנים תרמה–תרנ) |
| `src/sources/source-c.md` | **מכון הלכה חב"ד — מדריך מהיר** (מקור ג'; מנהג חב"ד; המקור: `chabad-guide.pdf`) |

כללי ההכרעה בין המקורות:
1. נושא שמקור ב' מכריע בו — ב' קובע.
2. ב' מביא דעות בלי הכרעה, וא' מכריע — הולכים לפי א'.
3. אף מקור אינו מכריע — 🟠 שאלת רב.
4. נושא שאין בב' — לפי א'.
5. במנהג חב"ד (נבחר בהגדרות) — מקור ג' קובע בכל נקודה שהוא מתייחס אליה; בשאר הנקודות — ב' וא'.
6. "יש להחמיר" / "לא לקחת אלא בשעת הדחק" — 🔴, וההסבר מציין שזו חומרה במחלוקת.

האפליקציה אינה תחליף לשאלת רב.

## מבנה

```
src/sources/     מקורות ההלכה (מילה במילה)
src/data/        rules.js (מאגר הכללים), questions.js (עץ השאלות), quiz.js (תרחישים)
src/js/          engine.js (מנוע ההחלטות, פונקציות טהורות), app.js (ממשק)
src/css/         styles.css
build.mjs        מאחד הכל לקובץ אחד: index.html (לאתר) ו-dist/arba-minim.html (ל-Artifact)
tests/           validate.mjs (כל מקור קיים, כל כלל מקושר), engine.test.mjs (48 בדיקות מנוע)
sw.js, manifest.webmanifest, icon.svg   עבודה אופליין והתקנה למסך הבית
```

## פיתוח

```bash
npm run build   # בונה את index.html מתוך src/
npm test        # בדיקת מקורות + בדיקות מנוע
```

אחרי כל שינוי ב-`src/` יש להריץ `npm run build` ולשמור גם את `index.html`. ה-CI בודק שהוא מעודכן.
כשמשנים הלכה: עדכן את `rules.js` ו-`questions.js`, הוסף בדיקה ב-`tests/engine.test.mjs`, והעלה את `VERSION` ב-`sw.js` כדי שטלפונים יקבלו את הגרסה החדשה.
